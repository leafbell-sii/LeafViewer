# 임시변경

작업 중 필요에 따라 기존 코드·스펙·도구를 바꾼 내용과 근거. 다음 세션이 점검하고, 이상이 없으면 지운다.

## v1.1 편집·새 파일 (2026-11-22)

| # | 변경 | 근거 | 점검할 것 |
|---|---|---|---|
| T-1 | 저장·파일 읽기(편집 시작)·새 파일/폴더 만들기를 **UI 스레드에서 동기로** 한다 (§4.2 "UI 스레드는 I/O를 기다리지 않는다"의 예외) | 결과(성공·실패)를 보고 바로 저장 확인 상자·편집 상태를 정해야 하고, 대상이 4MB 이하라 수 ms다 | 네트워크 드라이브에서 멈춤이 문제 되면 워커로 옮길지 |
| T-2 | 파일 트리 목록 창에 `WS_CLIPCHILDREN` 추가 | 이름 입력 EDIT(자식 창)를 목록 그리기가 덮지 않도록 | 없음 |
| T-3 | `treelist`의 빈 곳 우클릭이 `ListEvent::Menu(-1, pt)`를 낸다(전에는 무시). 목차 목록은 계속 무시 | FR-F10 빈 곳 메뉴 | 없음 |
| T-5 | 삭제는 `SHFileOperationW`(FO_DELETE)를 UI 스레드에서 동기로 부른다. 확인은 앱이 직접 묻고 셸 확인·오류 창은 끈다(휴지통 불가 경고만 켬) | 큰 폴더는 잠깐 멈출 수 있다. `IFileOperation`(진행 창)으로 바꿀지는 필요할 때 | 큰 폴더 삭제 체감 |
| T-4 | `leaf-win`이 `encoding_rs`에 직접 의존 (편집기가 UTF-8로 바꿔 저장할 때 `TextEncoding::new(UTF_8)`) | `leaf-fmt-text`에 이미 있는 같은 버전 | 없음 |
