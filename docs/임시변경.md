# 임시변경

작업 중 필요에 따라 기존 코드·스펙·도구를 바꾼 내용과 근거. 다음 세션이 점검하고, 이상이 없으면 지운다.

## M3 (MD 뷰어, 2026-11-21, 커밋 6229528)

### 스펙과 다르게 구현

| # | 변경 | 근거 | 점검할 것 |
|---|---|---|---|
| T-1 | 코드 블록과 표에 **가로 스크롤을 두지 않음**. 본문 폭 안에서 줄바꿈하고, 긴 단어는 강제로 끊음(`DWRITE_WORD_WRAPPING_EMERGENCY_BREAK`) | 블록 하나만 가로로 스크롤되게 하려면 블록별 가로 오프셋, 휠 방향 분기, 선택 좌표 보정이 필요하다. 가상화 레이아웃이 복잡해지는 데 비해 얻는 게 적다 | SPEC §4.4 구현 메모에 반영됨. 코드가 줄바꿈되는 것이 괜찮은지 결정 |
| T-2 | 8MB가 넘는 MD를 원문으로 열 때 "렌더링" **버튼 대신** 상태 표시줄 안내와 Ctrl+U | 상태 표시줄에 클릭할 수 있는 버튼 컨트롤이 아직 없다 | 미해결 U-16과 같은 항목. 버튼이 필요하면 UI 작업 때 처리 |
| T-3 | SPEC §10의 가짜 측정기 이름 `TextMeasurer` → `Measurer` | 실제 trait는 글자 외에 인라인 객체(이미지 자리)도 측정해서 이름을 바꿨다 | SPEC 본문과 코드(`leaf-layout/src/flow.rs`)의 이름이 맞는지 |

### 기존 코드 변경

| # | 변경 | 근거 | 점검할 것 |
|---|---|---|---|
| T-4 | `leaf-core::session::FilePos`에 `view: String` 필드 추가("pdf" / "txt" / "md"). `PdfView::restore`와 `TextView::restore`는 다른 보기에서 기록한 위치를 무시함 | 같은 MD 파일을 렌더링 보기와 원문(TXT) 보기 양쪽으로 열 수 있다. TXT의 바이트 오프셋을 MD 단위 번호로 잘못 해석하지 않으려면 구분해야 한다 | `#[serde(default)]` 덕분에 이전 세션 파일은 빈 값으로 읽히고 그대로 복원된다. 옛 session.toml로 실행해 확인 |
| T-5 | `app.rs` `saved_pos()`: `--bench-scroll` 모드에서는 저장된 위치를 복원하지 않음 | 벤치마크와 캡처가 지난번 위치(문서 중간·끝)에서 시작해 측정이 틀어졌다 | PDF·TXT 벤치마크도 이제 항상 처음부터 측정한다. M1·M2 수치와 비교할 때 유의 |
| T-6 | `textview.rs` `range_rects`를 `fn` → `pub(crate) fn` | MD 보기의 인라인 코드 배경, 찾기 강조, 선택 사각형 계산에 재사용 | 공용 모듈(예: `render.rs`)로 옮길지 |
| T-7 | `render.rs`: MD용 색 상수·브러시(link, code_bg, border, inline_code) 추가. `create_bitmap`을 알파 모드를 받는 `create_bitmap_with`로 분리하고 `create_bitmap_premul` 추가 | 투명 PNG(WIC 32bppPBGRA)는 미리 곱한 알파로 그려야 한다. 기존 PDF 경로는 `D2D1_ALPHA_MODE_IGNORE` 그대로 | 테마(다크 모드)가 생기면 색 상수를 테마로 옮길 것 |
| T-8 | `leaf-win` 의존성: `windows-core = "0.62.2"` 직접 추가, windows 기능에 `Win32_Graphics_Imaging` 추가 | `#[implement]` 매크로(DirectWrite 인라인 객체)가 `windows_core` 경로를 요구한다. Imaging은 WIC 이미지 디코딩용 | windows 크레이트를 올릴 때 windows-core 버전도 같이 맞출 것 |
