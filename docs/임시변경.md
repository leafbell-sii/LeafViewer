# 임시변경

작업 중 필요에 따라 기존 코드·스펙·도구를 바꾼 내용과 근거. 다음 세션이 점검하고, 이상이 없으면 지운다.

## M4 (다듬기, 2026-11-21)

### 스펙과 다르게 구현

| # | 변경 | 근거 | 점검할 것 |
|---|---|---|---|
| T-1 | Q9 트리 교체를 **D2D가 아니라 GDI**로 그리는 가상 목록(`treelist.rs`)으로 했다. 목차 탭도 같은 위젯을 쓴다 | 목록은 글자·아이콘·배경만 그리면 되고, GDI는 디바이스 손실 처리가 없어 코드가 짧다. 글꼴 연결로 한글도 나온다. 컬러 이모지 파일 이름은 흑백으로 보인다 | 이모지 파일 이름이 흑백이어도 되는지 |
| T-2 | 사이드바 탭(Tab 컨트롤)과 상태 표시줄(StatusBar)도 직접 그린다(`chrome.rs`). 상태 표시줄 크기 조절 손잡이는 없어졌다 | 공용 Tab·StatusBar 컨트롤은 다크 테마로 그릴 수 없다 | 없음 |
| T-3 | 다크 모드에 비공식 API 사용: uxtheme 서수 #135 `SetPreferredAppMode`·#136 `FlushMenuThemes`(우클릭 메뉴), 테마 클래스 `DarkMode_Explorer`(스크롤바)·`DarkMode_CFD`(찾기 입력란) | 문서화된 방법이 없다. SPEC §3.4가 이미 `DarkMode_Explorer`를 허용했다. 함수가 없으면 조용히 건너뛴다 | Windows 업데이트 뒤 메뉴가 계속 다크로 나오는지 |
| T-4 | 단축키 추가: **Ctrl+,** 설정 파일 열기(없으면 설명이 달린 기본 설정을 만든다), 마우스 X1/X2·브라우저 키 → 뒤로/앞으로·새로 고침 | SPEC에 설정 파일 여는 단축키가 없었다(도구 모음 [⚙] 대신) | SPEC §7.2에 반영함 |
| T-5 | 파일 감시 디바운스를 "첫 이벤트부터 200ms 뒤 한 번에 처리"(고정 창)로 했다 | 매 이벤트마다 타이머를 다시 거는 방식은 계속 쓰이는 로그 파일에서 영영 반영되지 않는다 | 없음 |
| T-6 | 뒤로/앞으로 기록 대상: 트리·링크·끌어다 놓기로 다른 문서를 연 경우, MD `#앵커`·PDF 문서 안 링크로 이동한 경우. **목차 클릭은 기록하지 않는다** | 목차를 ↑↓로 훑으면 기록이 넘친다 | 목차 이동도 기록할지 |
| T-7 | 설정 `[text] line_numbers`, `[memory] keep_recent_documents`, `[markdown] load_remote_images`는 읽기만 하고 쓰지 않는다. 설정 템플릿에도 넣지 않았다 | 해당 기능(줄 번호 U-08, 문서 캐시, 원격 이미지 클릭 로드)이 아직 없다 | 미해결 U-08·U-27 |

### 기존 코드 변경

| # | 변경 | 근거 | 점검할 것 |
|---|---|---|---|
| T-8 | `leaf-win/src/tree.rs` 삭제 → 트리 모델을 `leaf-core::tree`로 옮김(노드 번호 고정, 다시 읽기 diff, 단위 테스트) | 파일 감시로 폴더를 다시 읽을 때 펼침 상태를 지키려면 diff가 필요하고, UI 없이 테스트할 수 있다 | 없음 |
| T-9 | `Session`에 `sidebar_w`·`sidebar_hidden`·`expanded`, `FilePos`에 `wrap: Option<bool>` 추가 | FR-A02(사이드바 폭·펼친 폴더), U-09(줄바꿈 기억) | `#[serde(default)]`라 옛 세션도 읽힌다 |
| T-10 | `textload::load(path, mmap_threshold)`, `TextView::new(…, TextStyle, …)`, `MdView::new(…, MdStyle, …)`, `PdfView::new(…, bitmap_budget, default_zoom)`로 설정을 넘긴다. `leaf_fmt_markdown::RENDER_SIZE_LIMIT` 상수는 남았지만 앱은 설정값을 쓴다 | U-09·U-16 설정화 | 상수를 지울지 |
| T-11 | `pdfview::Cmd::Jumped`·`MdCmd::Jumped`(이동 전 위치) 추가 | 문서 안 이동을 뒤로 가기 기록에 남기려고 | 없음 |
| T-12 | 파일 하나를 열 때(명령줄·끌어다 놓기·단일 인스턴스) 상위 폴더가 이미 루트면 루트를 다시 만들지 않는다 | 같은 폴더 파일을 끌어다 놓을 때마다 트리가 접히지 않게 | 없음 |
| T-13 | 매핑으로 연 큰 TXT가 바뀌면 다시 읽기 전에 문서를 먼저 닫는다("파일이 바뀌어 다시 읽는 중…" 화면) | 매핑을 바로 놓아야 다른 프로그램의 다음 저장이 막히지 않는다(U-04) | 화면이 한 번 깜빡인다 |
| T-14 | GDI `DrawTextW`는 빈 문자열이면 부르지 않는다(`draw_text`) | 빈 `Vec<u16>`의 포인터는 가짜라 user32가 읽다가 접근 위반으로 죽었다(개발 중 실제로 발생) | 다른 Win32 슬라이스 API에도 같은 주의 |
